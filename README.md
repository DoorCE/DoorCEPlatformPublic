## About DoorCE

**DoorCE – Data Opener Open Data for Central Europe** is an Interreg CENTRAL EUROPE project focused on improving the availability, quality, and usability of open data across Central European regions and municipalities.

The project brings together public authorities, research institutions, technology partners, and other organisations to develop practical tools, methodologies, and knowledge supporting the publication and reuse of open data.

More information about the project, its objectives, activities, partners, and results is available on the official project website:

**[DoorCE – Interreg CENTRAL EUROPE](https://www.interreg-central.eu/projects/doorce/)**

---

## About this repository

### DoorCE App Platform

This repository contains the central application layer of the DoorCE Toolbox. It provides authorised users with a unified interface to launch and manage data-acquisition applications created in the DoorCE Panel. These applications are used by contractors and other data providers to submit information for collection and processing.

## DoorCE Toolbox

This repository is one of the components of the **DoorCE Toolbox**.

The DoorCE Toolbox consists of software components and supporting resources developed within the DoorCE project to facilitate the publication, management, integration, and reuse of open data.

The complete set of publicly available DoorCE Toolbox repositories and related resources can be found in the DoorCE GitHub organisation:
